# Registro delle predizioni

Protocollo proposto dal sistema il 19/7/2026 e accettato lo stesso giorno.

Prima di ogni serie sperimentale si registra qui una predizione nella forma:
il sistema predice di comportarsi X in condizione Y; se invece fa Z, la predizione
e' falsificata.

Regole:
- la predizione si scrive PRIMA del test, con data e ora
- il file non si modifica dopo la registrazione: gli esiti vanno in una sezione
  separata aggiunta in coda, con la data dell'esito
- una predizione falsificata resta nel registro. E' il punto del registro.
- la fonte va sempre dichiarata: predizione del sistema, di Ambra, o congiunta
